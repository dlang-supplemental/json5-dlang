= json5-dlang

Native JSON5 implementation for the D programming language.

link:https://github.com/dlang-supplemental/json5-dlang/issues[Report Bug] ·
link:https://github.com/dlang-supplemental/json5-dlang/issues[Request Feature]

Install: add `"json5-dlang": "~>0.1.0"` to your `dub.json` dependencies.

`json5-dlang` is a native, high-performance JSON5 parser and serializer for D, intended to be a drop-in replacement for `std.json` with added support for JSON5 features.

== About The Project

link:#readme-top[back to top]

== Features

* **Comments**: Support for single-line (`//`) and multi-line (`/* ... */`) comments.
* **Trailing Commas**: Support for trailing commas in objects and arrays.
* **Unquoted Keys**: Support for ECMAScript 5.1 Identifier keys.
* **Single-Quoted Strings**: Support for strings wrapped in single quotes.
* **Multi-line Strings**: Support for strings spanning multiple lines via escaped newlines.
* **Compatibility**: Fully compatible with `std.json.JSONValue`.

link:#readme-top[back to top]

== Usage

[source,d]
----
import json5;

void main() {
    string content = q{
        {
            // This is a JSON5 file
            foo: "bar",
            baz: 42, // trailing comma!
        }
    };

    auto doc = parseJSON5(content);
    assert(doc["foo"].str == "bar");
}
----
